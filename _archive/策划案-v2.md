# 《大模型编年史 · 创业模拟器》策划案 v2

> **产物形态**：小红书小工具（离线 H5，打包 zip，挂载到笔记）
> **类型**：树状决策养成 / 分支叙事
> **一句话**：你回到 2017、2020 或 2023 年，带着一笔钱和一堆显卡创立一家 AI 公司。12 个决策之后，你会成为谁？
> **设计红线**：**零 AI 知识也能玩**。做选择靠商业常识，AI 知识是通关后的奖励，不是门槛。
> **配套文档**：`美术设计规范-v1.md`（旧报纸铅印 × 机密档案卷宗风）
> **版本**：v2（2026-08-29 推翻 v1 重写）

---

## 0. 为什么推翻 v1

| | v1（已废弃） | v2 |
|---|---|---|
| 核心玩法 | 答题 → 掉卡 → 合成 → 模型升级 | 树状决策 → 资源变化 → 走向不同结局 |
| 玩家身份 | 旁观者（实验室主任） | **当事人（创业者）** |
| AI 知识的位置 | **门槛**（不懂就答不了题） | **奖励**（通关才解锁档案） |
| 重玩动力 | 收集图鉴 | "我这次能成为谁" |
| 失败的意义 | 扣分 | **反事实历史**（告诉你真实公司在这个岔路口选了什么） |

**v1 的根本错误**：把 AI 知识设成了准入门槛。对"只用过 chatbot"的用户，第一道题就卡死了。

**v2 的解法**：选择题全部是商业常识题（"要不要拿这笔钱""开源还是闭源"），不需要任何 AI 背景。AI 历史被拆成**结局后的档案**，玩完了才给你看 —— 想看全部档案，就得把 6 条路都走一遍。

## 3. 核心系统

### 3.1 五个可见资源

| 资源 | 含义 | 起始值（2020 起点） | 显示方式 |
|---|---|---|---|
| **资金** | 账面现金 | 3.0 亿 | `¥ 3.0 亿` |
| **算力** | 可用 GPU 卡 | 2,000 卡 | `2,000 卡` |
| **团队** | 核心研究员数 | 30 人 | `30 人` |
| **声誉** | 业界声望（影响融资与挖人） | 25 | 进度条 |
| **模型代际** | 你的最强模型到哪一代 | 无 | `GPT-2 级` |

**隐藏数值**：时间（推进的历史年份）、六条路径的倾向分。

### 3.2 三个起点（开局可选）

| 起点 | 时代背景 | 资金 | 算力 | 团队 | 声誉 | 难度 | 气质 |
|---|---|---|---|---|---|---|---|
| **2017** | Transformer 论文刚发表，没人看好 | 5000 万 | 500 | 8 | 10 | ★★☆ | 拓荒，时间充裕但起点低 |
| **2020** | GPT-3 已发布，窗口刚打开 | 3.0 亿 | 2,000 | 30 | 25 | ★★★ | 标准局，黄金窗口 |
| **2023** | ChatGPT 已爆火，百模大战 | 10 亿 | 8,000 | 80 | 40 | ★★★★★ | 地狱，资源多但巨头已成型 |

不同起点**决策树部分共用、部分专属**，且随机事件的激烈程度递增。

### 3.3 决策系统（核心）

每个决策节点 = 一张场景卡 + 2-4 个选项。

```
┌──────────────────────────────────┐
│  第 3 / 12 决定        2021 年     │
│                                  │
│  你的模型能写代码了，但经常写错。  │
│  投资人开始找上门。               │
│                                  │
│  ┌────────────────────────────┐  │
│  │ A  拿大钱，先把模型做大      │  │
│  │    资金 ++++  独立度 --     │  │
│  └────────────────────────────┘  │
│  ┌────────────────────────────┐  │
│  │ B  不拿，保持独立慢慢做      │  │
│  │    资金 --  声誉 ++         │  │
│  └────────────────────────────┘  │
│  ┌────────────────────────────┐  │
│  │ C  拿钱，但只接受有安全条款的│  │
│  │    资金 ++  声誉 +          │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

**选项结构（开发用）**

```json
{
  "id": "d3_a",
  "text": "拿大钱，先把模型做大",
  "hint": "资金 ++++  独立度 --",
  "effects": { "cash": 80, "compute": 6000, "reputation": 5, "independence": -20 },
  "path": { "openai": 3, "anthropic": -2, "moonshot": 1 },
  "echo": "2019 年的 OpenAI 也站在这里。他们选了这条路。"
}
```

`echo` 字段是**回声机制** —— 选定后短暂显示一句真实历史的对照，不打断节奏，但埋下"原来历史上真有人这么选过"的种子。

### 3.4 随机事件系统

每隔 2-3 个决策，砸下来一个**真实历史事件**，玩家必须应对（或承受后果）。这让"我在真空里做选择"变成"我正站在历史的岔路口"。

| 事件 | 时间 | 冲击 |
|---|---|---|
| ChatGPT 爆火 | 2022.11 | 所有人的路线被重新评估，To C 窗口打开 |
| Llama 权重泄露 | 2023.02-04 | 开源模型免费可得，闭源 API 定价承压 |
| 董事会政变 | 2023.11 | 若拿了太多外部钱，触发创始人被驱逐危机 |
| FTX 暴雷 | 2022.11 | 若早期拿了 SBF 的钱，资金归零风险 |
| DeepSeek 降价 | 2025.01 | 全行业推理成本被打到 1/10，定价策略失效 |
| 芯片管制 | 2023-2025 | 算力获取成本飙升，囤卡与否决定生死 |
| 万亿参数军备 | 2025-2026 | 不跟进就掉队，跟进就烧钱 |

### 3.5 结局判定

12 个决策结束后，按六条路径的隐藏倾向分 + 资源终值综合判定：

```
结局 = argmax( pathScore[6条] ) 且 满足该路径的准入门槛

准入门槛例：
  OpenAI 路径：资金 ≥ 50 亿 且 算力 ≥ 5 万卡
  DeepSeek 路径：算力效率 ≥ 阈值 且 独立度 = 100
  Anthropic 路径：安全投入 ≥ 3 次 且 独立度 ≥ 60
```

不满足任何门槛 → 落入**平庸结局**或**失败结局**。

## 6. 失败与平庸结局（4 个，同样解锁档案）

| 结局 | 触发条件 | 结局卡 | 反事实档案 |

| **被驱逐** | 独立度 < 30 且 拿了超大轮 | "董事会投票把你赶出了自己创立的公司。你带走了一支团队，重新开始" | **这正是 2023 年 11 月发生在 Altman 身上的事**——区别是他有微软撑腰，五天后就回来了 |
| **护城河蒸发** | 差异化技术被追平 且 在烧钱投流 | "你引以为傲的技术，对手用三分之一的成本做出来了。你的用户开始流失" | **2024 下半年的 Kimi**——长上下文被 DeepSeek 和开源模型磨平。杨植麟的应对是：停投流，回去把模型做到万亿参数并开源 |

## 10. 技术约束（小红书小工具）

| 约束 | 要求 |
|---|---|
| 产物 | `.zip`，`index.html` 在**根目录**（压缩目录内容，不能多套一层） |
| 网络 | **纯离线**，禁止 fetch / CDN / 外链，所有资源打进包 |
| 脚本 CSP | 禁止内联 `<script>`、`onclick=`、`eval`、`new Function`、`type="module"`、`import/export` |
| 脚本写法 | 外置 `.js`，`addEventListener` 绑事件，多文件按顺序 `<script src>` + `window` 命名空间 |
| 样式 | `<style>` 内联可用 |
| 存储 | localStorage / IndexedDB（按小工具隔离） |
| 原生 API | 仅 `postNote` / `saveImageToPhotosAlbum` / `openRedPage` / `writeTempFile` |
| 禁用 | Worker、Service Worker、WebSocket、geolocation、clipboard、window.open、iframe、WASM |
| 体积 | 上限 10MB，建议 2MB 内 |
| 跨端 | 安全区用 `var(--safe-area-inset-*, env(safe-area-inset-*, 0px))` |

## 13. 风险与待定

| 风险 | 说明 | 应对 |
|---|---|---|
| **决策太多导致疲劳** | 12 个决策 × 3-4 选项，对碎片时间可能偏长 | MVP 先做 12 个，实测后考虑砍到 8-9 个 |
| **人物结局的敏感性** | 涉及真实在世人物与公司 | 档案只写公开可查的事实（融资、论文、产品发布），不做评价；结局卡用中性语气 |
| **路径判定不透明** | 玩家不知道自己为什么走到这个结局 | 结局页展示"你的关键选择"回顾（3 个决定性节点） |
| **数值不平衡** | 某条路径明显更容易达成 | MVP 实测后调门槛 |
| **档案字数** | 10 份档案的文本量 | 每份控制在 300-500 字，纯文本约 5-8KB，10 份不足 80KB，体积无压力 |
