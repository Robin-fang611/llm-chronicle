# 大模型进化实验室 · 策划案 v1

> **产物形态**：小红书小工具（离线 H5，打包成 zip，挂载到笔记里）
> **一句话定位**：你是 AI 实验室主任，从 2017 年白手起家，答题攒卡、合成模型，一路造到 2026 年最强 AI。
> **设计红线**：**不能假设玩家有任何 AI 知识**。只用过 chatbot 的人，30 秒内必须能玩起来。

---

## 1. 玩家是谁

| 维度 | 描述 |
| --- | --- |
| 主要人群 | 小红书用户，用过 ChatGPT / 豆包 / Kimi，但说不清 GPT 和 BERT 的区别 |
| 场景 | 等电梯、睡前、通勤 —— 单次 3-10 分钟 |
| 心理 | 对 AI 好奇但怕硬核；喜欢收集、成就、晒成绩 |
| 上手门槛 | **零 AI 知识**。所有专业内容必须翻译成"人话" |

## 2. 总规则（这是全案最重要的一节）

### 三句话规则

```
1. 你是一个 AI 实验室主任
2. 答题攒卡片，卡片合成模型
3. 抢在别人前面，造出最强的 AI
```

### 30 秒上手

```
① 点「开始」→ 穿越到 2017 年，实验室刚成立
② 答题 → 拿到「人物卡」和「技术卡」
③ 把两张卡拖在一起 → 合成出模型
④ 模型越新，实验室越强
⑤ 通关一个时代 → 结算拿 1-3 星
```

### 完全不懂 AI？没关系

每张卡都带一句**人话说明**，题目不考公式、不考参数，只考常识和直觉：

| 术语 | 卡面上的"人话说明" |
| --- | --- |
| Transformer | 让 AI 学会「抓重点」的发明 |
| Scaling Law | 喂得越多、算得越久，AI 越聪明 |
| RLHF | 人类给 AI 打分，让它学会说人话 |
| MoE | 一个团队 100 个专家，每次只叫 2 个上班 |
| 扩散模型 | 先把照片涂满噪点，再一步步擦干净 |
| LoRA | 给大模型打补丁，不用整个重训 |
| In-Context Learning | 给 AI 看几个例子，它就会了 |
| 长上下文 | AI 的「记性」变好了，能一次读完好几本书 |

### 怎么算赢

```
每章 1-3 星，5 章共 15 星

  通关本章            → 1 星
  又快（轮数 ≤ 预算）  → +1 星
  又准（正确率 ≥ 80%） → +1 星

集齐 15 星 = 图灵奖得主
```

**为什么用星级而不是积分**：玩家秒懂（不用教学）、天然防磨分（想拿 3 星必须又快又准）、有明确终极目标（全 3 星）。

## 3. 核心循环

```
        ┌──────────────────────────────┐
        │                              │
        ▼                              │
   【答题闯关】 ──答对──▶ 【掉落卡片】  │
        │                      │       │
        │                      ▼       │
        │              【实验室合成】   │
        │                      │       │
        │                      ▼       │
        │              【模型升级】     │
        │                      │       │
        │                      ▼       │
        │              【图鉴点亮】     │
        │                      │       │
        └─────算力不够？────────┘       │
              回溯答题 ◀────────────────┘
```

- **答题**消耗 1 轮算力，掉落 1-2 张卡
- **合成**消耗卡片，产出模型（消耗卡片但不消耗算力）
- 算力是每章的**预算**，用完即结算 —— 逼玩家做取舍

## 4. 多支线设计（5 条技术路线）

玩家不必走完所有线，**算力有限，必须选**。这是策略深度的来源。

### 线 A · GPT 线（OpenAI / 自回归路线）

> 主线气质：一路堆规模，用 RLHF 让 AI 会聊天

| 配方 | 产物 |

| 自回归 + 无监督预训练 | GPT-1 |
| GPT-1 + Scaling Law | GPT-2 |
| GPT-2 + Scaling Law | GPT-3 |
| GPT-3 + RLHF | ChatGPT |
| ChatGPT + 多模态 | GPT-4 |
| GPT-4 + 思维链 | o1（会思考的模型） |
| o1 + 智能体 | GPT-5 |

### 线 C · 开源线（Meta / 社区 / 人人可用）

> 主线气质：把 AI 从大公司手里解放出来

### 线 D · 国产线（中国力量）

## 7. 题库设计原则（小白友好 —— 本项目的生死线）

### ❌ 绝对不能这样出题

- "GPT-3 有多少参数？" → 小白不知道，直接劝退
- "Transformer 论文的全称是？" → 背书题，无聊
- "RLHF 的中文全称是？" → 术语题，劝退
- "以下哪个不是 MoE 模型的代表？" → 反向选择题，烦

### ✅ 要这样出题：考常识、考直觉、考类比

**题型 1 · 类比题**（把 AI 概念翻译成生活经验）

> AI 学会聊天，最像小孩学说话的哪一步？
> A. 背字典　B. 听大人说话然后模仿　C. 上课学语法　D. 看动画片
> ✅ B（预训练的本质：从海量文本里学规律）
> 解析：AI 不是背规则，是像小孩一样"听多了就会了"。

**题型 2 · 场景题**（用得上的直觉）

> 你让 AI 写辞职信，它写得太生硬。最有效的办法是？
> A. 骂它一顿　B. 给它看几个写得好的例子　C. 换一个 AI　D. 自己写
> ✅ B（In-Context Learning）
> 解析：给 AI 看例子比讲道理管用 —— 这也是"提示词"的核心。

**题型 3 · 因果题**（理解技术演进的逻辑）

> 如果给 AI 喂 10 倍的数据和 10 倍算力，最可能发生什么？
> A. 它明显变聪明　B. 完全没变化　C. 它变笨了　D. 它开始有自我意识
> ✅ A（Scaling Law）
> 解析：这就是"大"模型大的原因 —— 规模本身就是能力。

**题型 4 · 直觉题**（反常识，有记忆点）

> 你觉得 AI 最容易先学会的是哪个？
> A. 写代码　B. 讲笑话　C. 安慰人　D. 品咖啡
> ✅ A
> 解析：规则越清晰的任务 AI 学得越快；越需要"人味"的越难。

**题型 5 · 判断题**（30 秒内能答）

> AI 是真的"理解"了它在说什么吗？
> A. 真的理解　B. 只是在预测下一个字　C. 大部分时候理解
> ✅ B
> 解析：大模型的本质是高维的"下一个字预测器" —— 但预测得足够好，看起来就像理解了。

### 出题三条铁律

1. **不考数字**（参数量、日期、版本号一律不出）
2. **不考术语**（除非题目本身就在解释这个术语）
3. **每题必带解析**（答完立刻学到东西，解析比题目更重要）

### 段位（按总星数）

| 星数 | 段位 |
| --- | --- |
| 1-3 | 实习生 |
| 4-6 | 初级研究员 |
| 7-9 | 研究员 |
| 10-12 | 高级研究员 |
| 13-14 | 首席科学家 |
| 15 | 图灵奖得主 |

### 排行榜：离线环境的三种替代

> 小红书小工具**纯本地离线、无后端、无账号** —— 真·跨用户排行榜做不了。

**① 虚拟同期群**（主力方案）
预设 100 名虚拟对手，星数按正态分布铺开（中位数 7-8 星），玩家结算时插入算百分位 → 显示"你击败了 87% 的实验室主任"。
对手名字用 AI 圈梗：奥特曼的实习生、炼丹炉守夜人、调参侠、显卡矿工、论文搬运工、硅谷老王……

**② 本地最佳记录**
localStorage 存历史最佳，下次进来显示"上次第 23 名，这次第 11 名"。

**③ 成绩卡分享**（小红书生态最自然的社交比较）
结算页 Canvas 画一张成绩卡：段位 + 星数 + 击败百分比 + 图鉴收集率
→ `saveImageToPhotosAlbum` 存相册 / `postNote` 直接发笔记

### 图鉴成就

- 每合成/获得一张卡，图鉴点亮一格
- 全图鉴（约 60 张）→ "大模型通"成就
- 每条支线走通 → 该线的专属徽章（如"开源先锋""推理大师"）

## 10. 技术约束（小红书小工具硬限制）

| 约束 | 要求 |
| --- | --- |
| 产物 | `.zip`，`index.html` 在**根目录**（压缩目录内容，不能多套一层） |
| 网络 | **纯离线**，禁止 fetch / CDN / 外链图片字体，所有资源打进包 |
| 脚本 CSP | 禁止内联 `<script>`、`onclick=`、`eval`、`new Function`、`type="module"`、`import/export` |
| 脚本写法 | JS 全部外置 `.js`，`addEventListener` 绑事件，多文件按顺序 `<script src>` + `window` 命名空间 |
| 样式 | `<style>` 内联可用 |
| 存储 | localStorage / IndexedDB 可用（按小工具隔离） |
| 原生 API | 仅 `postNote` / `saveImageToPhotosAlbum` / `openRedPage` / `writeTempFile` 四个 |
| 禁用 | Worker、Service Worker、WebSocket、geolocation、clipboard、window.open、iframe、WASM |
| 体积 | 上限 10MB，建议 2MB 内 |
| 跨端 | PC 模拟器 + 真机 WebView，安全区用 `var(--safe-area-inset-*, env(safe-area-inset-*, 0px))` |

## 附：这个设计真正的护城河

合成配方本身就是知识：

```
Attention 论文 + 算力        = Transformer
Transformer + 双向编码      = BERT
Transformer + 自回归 + 规模  = GPT-3
GPT-3 + RLHF              = ChatGPT
扩散模型 + CLIP            = DALL·E
MoE + 极致省钱             = DeepSeek-V3
```

玩家瞎试配方的过程，其实是在**自己发现** AI 史的因果链 —— 这比答 100 道选择题强得多。他是"推导"出了技术演进的逻辑，而不是被灌输。

**别把它做成纯答题游戏。**
