# 《大模型编年史 · 创业模拟器》美术设计规范 v1

> 形态：小红书小工具 · 纯离线 H5 · 移动端竖屏优先（375–430px）
> 硬约束：零外部资源（无 CDN / 无外链图 / 无 woff）· 系统字体栈 · 图形用纯 CSS + 内联 SVG · 总包 ≤ 2MB
> 设计原则：**美术是配角**。只用「版式 + 线条 + 两种套色」撑质感，不画插画、不做立绘。

---

## 1. 复古方向选型

### 候选对比

| 方向 | 气质 | 适配度 | 实现成本 | 判定 |
|---|---|---|---|---|
| A. 80s CRT 终端荧光绿 | 极客、黑客、孤独感强 | 中 | 极低 | 落选。单色难承载「成功/失败/警告」多状态；纯绿对小红书用户有疏离感，且「商业决策」氛围偏冷 |
| B. 90s DOS / Windows 3.1 灰蓝 | 官僚、企业软件、呆板 | 中高 | 低 | 落选。视觉枯燥、情绪扁平，撑不起「豪赌感」与结局的身份认同 |
| **C. 老报纸铅印 + 档案卷宗** | 新闻、史料、机密、黑色幽默 | **高** | 低 | **推荐** |
| D. 8-bit 像素游戏 | 游戏感强 | 中 | **高** | 落选。像素需位图或大量 `box-shadow` 堆砌，包体与维护成本超标，且与「严肃档案」冲突 |
| E. 早期 Macintosh 黑白位图 | 极简、怀旧 | 中 | 中 | 落选。1-bit 纯黑白，中文小屏可读性差，无套色则状态表达缺失 |

### 推荐方向：**C — Newsprint Dossier（旧报纸铅印 × 机密档案卷宗）**

一句话定义：**这是一份 2017 年的旧报纸，夹着一份被解密的创业档案。**

为什么是它：

1. **产品名就叫「编年史」**，报纸/档案是最自然的视觉隐喻，玩家零学习成本理解「我在读历史」。
2. **机制与视觉同构**：随机大事件 = 报纸号外头条；结局卡 = 人物专访版式（解决身份认同）；档案时间轴 = 解密卷宗（解决知识获得感）。
3. **灰色 + 单点套红**，配色收敛、零位图，成本≈纯 CSS，靠版式和硬阴影撑质感而不显廉价。
4. **黑色幽默天然载体**：报纸标题体措辞（「某公司今日宣布融资，金额不予披露」）自带讽刺，无需画图。
5. **小屏可读性最好**：纸黄底 + 墨黑字对比度 ≈ 12.9:1，远超 WCAG AAA。

视觉关键词：**直角、硬阴影、双线、密集字距、大写英文 kicker、半调网点、套印错位、等宽数字**
反关键词：圆角卡片、渐变、玻璃拟态、柔和投影、emoji 装饰、卡通插画

### 2.3 套色（强调 / 状态，全屏使用面积 ≤ 15%）

|---|---|---|---|
| `--accent` | `#B23A2E` | **主强调色**：套红标题、警示、失败、损失数值、报头刊头 | 5.1:1（≥14px 粗体或标题/图标） |
| `--accent-dark` | `#8C2A20` | 套红按下态、深红底块 | — |
| `--info` | `#33566E` | 中性信息：档案编号、链接、算力/技术类标签 | 5.4:1 |

| `--warn` | `#C77B22` | 临界警告（资金见底、团队动摇） | 3.2:1（**仅用于图标+加粗短标，不用于长正文**） |
| `--gold` | `#A8801F` | 成就、解锁、星级评价、烫金印章 | 3.6:1（仅用于印章/星标等非文字或大号字） |

### 2.4 遮罩与纹理

- `--scrim: rgba(26,24,21,.72)` —— 弹窗遮罩，不用纯黑以保纸感。
- `--noise` —— 内联 SVG `feTurbulence` data-uri（见 §6），`opacity:.045` + `mix-blend-mode:multiply`。
- `--halftone: radial-gradient(circle at center, #1A1815 .9px, transparent 1px)` + `background-size: 4px 4px` —— 仅小面积装饰。

## 3. 字体方案

### 3.1 字体栈

```css
/* 正文 / UI 主体 */
--font-sans: -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB",
             "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;

/* 展示体：报头、大标题。中文优先宋体（铅印感），无宋体时优雅降级到无衬线 */
--font-display: "Songti SC", "STSong", "SimSun", Georgia, "Times New Roman",
                "PingFang SC", "Microsoft YaHei", serif;

/* 数字 / 年份 / 档案编号 / 英文 kicker */
--font-mono: ui-monospace, "SFMono-Regular", Menlo, Consolas, "Courier New", monospace;
```

> **宋体降级说明**：Android 无 `Songti SC`，会回落到系统 serif（多为 Noto Serif CJK，观感可接受）；若真机验证不理想，把 `--font-display` 末尾改为 `sans-serif` 即可整体降级，不影响版式。
> **禁止**：任何 `@font-face`、任何 woff/woff2、任何外链字体。

### 3.2 字号阶梯（1rem = 16px，禁用户缩放前提下）

| Token | 值 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `--fs-display` | `2.25rem` / 36px | 1.15 | 700 | 报头刊名、结局人物名 |
| `--fs-h1` / `--fs-h2` | `1.5rem`/24px · `1.25rem`/20px | 1.25 · 1.3 | 700 | 决策问题、弹窗标题 · 卡片标题、头条副标 |
| `--fs-h3` / `--fs-body` | `1.125rem`/18px · `1rem`/16px | 1.4 · **1.7** | 700 · 400 | 小节标题、数值主显示 · 正文、选项描述 |
| `--fs-sm` / `--fs-xs` | `0.875rem`/14px · `0.75rem`/12px | 1.6 · 1.4 | 400 · 500 | 次级说明、时间轴条目 · 标签、单位、注释 |
| `--fs-kicker` | `0.6875rem` / 11px | 1.2 | 700 | 大写英文 kicker，`letter-spacing: 2px` |

**规则**：正文最小 16px；`--fs-xs` 及以下不得用于成段文本，仅作标签/单位。

### 3.3 字重与字距

- 只用 **400 / 500 / 700** 三档（Android 对 600 常做合成渲染，观感脏）。
- 标题字距收紧 `letter-spacing:-0.01em`；kicker 放开 `letter-spacing:2px` 且 `text-transform:uppercase`。
- 所有数字容器加 `font-variant-numeric: tabular-nums;`（防跳动）。
- 中文标题换行：`line-break:strict; word-break:break-word; text-wrap:balance;`

## 4. 核心组件视觉规范

> 全局基线：**圆角 0–2px**（复古＝直角）、**阴影一律零模糊硬阴影**、**边框 ≥1px 实线**。

### 4.1 决策卡片

「这是个选择」的表达 = **左侧序号方块 + 上下双线 + 硬阴影 + 选中反白**。

```
┌────────────────────────────────┐  ← border-top: 3px solid var(--ink)
│ ┌──┐                           │
│ │ A│  选项标题 18px/700         │
│ └──┘  描述正文 16px/1.7         │
│        ┌─────────┐             │
│        │ 资金 -20 │  ← 后果标签 │
│        └─────────┘             │
└────────────────────────────────┘  ← border-bottom: 1px solid var(--rule)
```

| 属性 | 值 |
|---|---|
| 盒模型 | `width:100%`；`min-height:88px`；`padding:14px 16px 14px 56px`（左留序号位）；卡片间距 `12px` |
| 底色 / 边框 | 底 `var(--paper-2)`；`border:1px solid var(--ink)`；`border-top-width:3px`；圆角 `0` |
| 阴影 | `3px 3px 0 var(--ink)` |
| 序号方块 | `position:absolute; left:14px; top:14px; 24×24px`；`--font-mono` 18px/700；底 `--paper-3`，`border:1px solid var(--ink)` |
| **选中态** | 底 `var(--ink)`；文字 `var(--on-ink)`；序号块反白（底 `--paper-0`，字 `--ink`）；`border-left:6px solid var(--accent)`；阴影 `2px 2px 0 var(--accent)` |
| 按下态 | `transform: translate(3px,3px)`；`box-shadow: 0 0 0 var(--ink)`（阴影被"压平"） |
| 禁用态 | 底 `--paper-3`；字 `--ink-3`；无阴影；叠 `--halftone` 网点 `opacity:.12` |
| 后果标签 | 12px/700；正向 `--success` / 负向 `--accent` / 中性 `--info`；`border:1px solid currentColor`；`padding:2px 6px` |

### 4.2 资源面板（资金 / 算力 / 团队 / 声誉）

固定在顶部，**反白报头条**，与下方纸黄形成强对比。

| 属性 | 值 |
|---|---|
| 容器 | `position:sticky; top:0; z-index:20`；底 `var(--ink-block)`；`padding: calc(10px + var(--sat)) 16px 10px` |
| 布局 | `display:grid; grid-template-columns:repeat(4,1fr); gap:0`；每列右侧 `1px solid var(--on-ink-rule)`（末列无） |
| 单列 | 标签 11px/700 `--on-ink-dim`（中文＋英文 kicker，如「资金 / CASH」）；数值 18px/700 `--font-mono`，色 `var(--on-ink)` |
| 数值变化 | 上升 `--success-lit #7FB069`；下降 `--accent-lit #E0685A`；均配 `animation: num-pop .3s` |
| 临界态 | 数值 ≤ 阈值时整列 `animation: alert-pulse 1.2s infinite`（仅变亮度，不变位） |
| 高度 | 内容 44px + 安全区，总高 ≤ 76px |

> 深色面板**只此一处**，其余一律纸系底 —— 反白面积 >30% 就丢了纸感。

### 4.3 结局卡片（「你成为了 XXX」）

版式参照报纸**人物专访 / 头版讣告**，仪式感来源＝排版而非插画。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 3px 粗线
FINAL · 结局                    ← kicker 11px / 字距 2px
┌────────┐  你成为了            ← 16px --ink-2
│ [ 网点 │  Sam Altman          ← 36px/700 --font-display
│  头像位]│  ────────           ← 40×2px --accent 短线
│  1:1   │  判词 2-3 行 16px/1.7
└────────┘
[ 解锁真实档案 → ]                ← 主按钮
━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 1px 细线
```

| 元素 | 规范 |
|---|---|
| 容器 | 全屏层，底 `var(--paper-0)`；`padding: calc(24px + var(--sat)) 20px calc(20px + var(--sab))` |
| 头像位 | `112×112px`（1:1）；`border:2px solid var(--ink)`；底 `--paper-2` + `--halftone` 网点；中央放**姓名首字** 48px `--font-display`/700/`--ink-2`；右下角叠 `--accent` 小色块制造套印错位 |
| 人名 / 判词 | 人名 `--fs-display` / `--font-display` / 700 / `--ink`；判词 `--fs-body` / `--ink-2` / 1.7，首句加粗 `--ink` |
| 星级 | 3 个 16px 方块，`--gold` 填充 / `--rule` 描边 |
| 入场 | 粗线 `scaleX(0→1)` 220ms → 人名 fade-up 180ms（延迟 120ms）→ 判词打字机 → 按钮 120ms |

### 4.4 档案时间轴（解锁后的公司发展史）

| 元素 | 规范 |
|---|---|
| 主轴线 | `position:absolute; left:7px; top:0; bottom:0; width:2px; background:var(--ink)` |
| 节点 | **10×10px 实心方块**（非圆点，方块更复古）；未解锁 `--ink`，已解锁 `--accent`；`outline:2px solid var(--paper-1)`（挖空纸色描边） |
| 条目 | `position:relative; padding-left:28px; padding-bottom:20px` |
| 文字 | 年份 `--font-mono` 14px/700 `--ink`；标题 16px/700 `--ink`；正文 14px/1.6 `--ink-2` |
| **未解锁** | 整条 `opacity:.45`；标题覆「涂黑条」`repeating-linear-gradient(90deg, var(--ink) 0 6px, transparent 6px 9px)`；标签 `--font-mono` 11px 「CLASSIFIED / 未解锁」 |
| 解锁动效 | 涂黑条 `clip-path: inset(0 0 0 100%) → inset(0)` 400ms，配节点 `scale(0→1)` + 一次 `jitter` |

### 4.5 进度指示

采用**报纸页眉**而非进度条球。

```
VOL.01  ·  2017  ·  决策 03 / 10
▓▓▓░░░░░░░░░░░░░░░░░░   ← 10 段方块，flex:1，高 4px，间隙 2px
```

| 元素 | 规范 |
|---|---|
| 文字行 | `--font-mono` 12px/700 `--ink-2`；当前序号用 `var(--ink)` + `--accent` 底反白小块 |
| 方块条 | `display:flex; gap:2px; height:4px`；已完成 `--ink`；当前 `--accent`；未完成 `--rule` |
| 位置 | 资源面板下方，`padding:10px 16px 12px`，底部 `1px solid var(--rule-strong)` |
| 换章动效 | 整条 `scaleX` 0→1 展开 300ms + 一次全屏 `scanline` 闪过 |

### 4.6 按钮与弹窗

**按钮**（全部圆角 `0`，`min-height:48px`，底部按钮 `margin-bottom: var(--sab)`）

| 类型 | 规范 |
|---|---|
| 主按钮 | 底 `--ink-block`；字 `--on-ink`；18px/700；`letter-spacing:2px`；`padding:14px 20px`；`border:2px solid var(--ink)`；**硬阴影 `3px 3px 0 var(--accent)`（红色套印错位）** |
| 次按钮 | 底 `transparent`；字 `--ink`；`border:2px solid var(--ink)`；无阴影 |
| 危险/套红 | 底 `--accent`；字 `#FFFFFF`；`border:2px solid var(--ink)`；阴影 `3px 3px 0 var(--ink)` |
| 禁用 | 底 `--paper-3`；字 `--ink-3`；`border:1px dashed var(--rule)`；无阴影 |
| 按下 | `transform: translate(3px,3px); box-shadow: none`（保留 border） |

**弹窗**

| 属性 | 值 |
|---|---|
| 遮罩 | `background: var(--scrim)`；`backdrop-filter` **不用**（移动端性能与兼容风险） |
| 卡片 | 底 `var(--paper-0)`；`width:calc(100% - 40px); max-width:340px; max-height:80vh; overflow-y:auto` |
| 边框 / 阴影 | `border:2px solid var(--ink)`；阴影 `6px 6px 0 rgba(26,24,21,.22)`（**不用纯 ink** —— 纯黑硬阴影在深遮罩上不可见） |
| 顶部红条 | `::before` 高 `8px` 通栏，`background: var(--accent)` |
| 内边距 | `20px 20px calc(20px + var(--sab))` |
| 入场 / 关闭 | 遮罩 `opacity 0→1` 160ms；卡片 `translateY(12px)→0` + `opacity` 240ms `var(--ease)`；右上角 32×32 方块关闭键，`border:1px solid var(--ink)`，内部 CSS 画 × |

### 4.7 随机事件提示条（历史大事件砸下来）

样式＝**报纸号外**，全宽横条从顶部砸下。一局 ≤ 3 次（用多则冲击感钝化）。

| 元素 | 规范 |
|---|---|
| 容器 | `width:100%`；底 `var(--accent)`；上 `3px solid var(--ink)` + 下 `1px solid var(--ink)` 双线；`padding:12px 16px` |
| kicker | 「号外 / BREAKING」11px/700；底 `--paper-0`，字 `--accent`；`padding:2px 8px`；`letter-spacing:3px` |
| 标题 / 副标 | 标题 20px/700 `#FFFFFF`；副标 13px/1.5 `rgba(255,255,255,.82)` |
| 入场 / 停留 | `translateY(-100%)→0` 260ms + `jitter` 2 帧 + `scanline` 扫过 1 次；停留 3.5s 自动消失或点击关闭 |
| 变体 | 「政策/监管」类用 `--info` 底；「融资/突破」类用 `--ink-block` 底 |

## 5. 动效建议（仅 transform / opacity）

| 名称 | 思路 | 时长 / 曲线 |
|---|---|---|
| `typewriter` | 单行：`width: 0→100%` + `steps(n)` + `nowrap` + `overflow:hidden` + `border-right: 2px solid var(--ink)` 光标闪。多行分段用 `clip-path: inset(0 100% 0 0 → 0)` | 每字符 28ms；光标 `blink 1s steps(2) infinite` |
| `scanline` | 覆盖层 `repeating-linear-gradient(rgba(0,0,0,.06) 0 1px, transparent 1px 3px)`，`translateY(-100%→100%)` 一次 | 600ms linear；常态 `opacity:.05`，扫过 `.12` |
| `jitter` | `translate(0,0)→(-1px,1px)→(1px,-1px)→(0,0)`，`steps(1)` 逐帧 | 120ms，2 循环 |
| `paper-turn` | `transform-origin: top; rotateX(-8deg)→0` + `opacity .6→1` | 320ms `var(--ease)` |
| `num-pop` | `translateY(-4px)→0` + `opacity .4→1` | 300ms |
| `stamp-in` | 印章/结局标记 `scale(1.6)→1` + `opacity 0→1` + `rotate(-6deg)` | 240ms `var(--ease-pop)` |
| `reveal` | 档案涂黑条 `clip-path: inset(0 0 0 100%) → inset(0)` | 400ms |
| `alert-pulse` | 临界资源 `opacity 1→.45→1` | 1200ms infinite |

**通用规则**

- 微交互 ≤ 160ms；面板/卡片 240–320ms；过场 ≤ 600ms。单局累计动画时长 ≤ 8s。
- 只允许 `transform` / `opacity` / `clip-path`。禁止动画 `box-shadow`、`filter: blur()`、大面积 `background-position`（移动端掉帧）。
- 全量包裹 `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration:.01ms !important; transition-duration:.01ms !important } }`

## 6. CSS 变量清单（直接复制可用）

## 7. 避坑清单

1. **对比度不足**：`--accent #B23A2E`（5.1:1）、`--success #3F6B45`（4.6:1）只用于 ≥14px 粗体、标题或图标+短标；`--warn #C77B22`（3.2:1）、`--gold #A8801F`（3.6:1）**禁止承载长正文**。状态色必须配冗余编码（「↓ 资金 -20」不能只靠变红）。
2. **噪点过糊**：`--noise` 的 `opacity` 上限 **0.05**，超过则文字发灰、截屏更脏。颗粒只用 `feTurbulence` 的 SVG data-uri，**不用**位图 PNG（体积 + 平铺接缝）。
3. **网点摩尔纹**：半调间距 ≥ 4px，3px 以下在 OLED 上出摩尔纹且文字边缘发毛；网点总面积 ≤ 单屏 10%。
4. **字号过小**：正文 16px 起步，12px 只做标签/单位，11px 只做英文 kicker。中文 14px 以下的长段落必糊。
5. **直角滑向"没做完"**：直角本身不产质感，三件套必须齐 —— **实线边框 ≥1px + 零模糊硬阴影 + 上下双线分隔**，缺一即垮。
6. **装饰喧宾夺主**：每屏装饰 ≤ 1 处；扫描线常态 `opacity ≤ 0.06`，且不在正文滚动时持续移动（晕眩 + 掉帧）。
7. **宋体 fallback 风险**：Android 无 `Songti SC`，必须真机核对报头与结局人名；不理想就把 `--font-display` 末位改 `sans-serif` 整体降级。
8. **白色区块破功**：禁止任何 `#FFFFFF` 区块（仅 `--accent` 底上的按钮文字例外）。卡片一律纸系 4 档。
9. **反白面积失控**：`--ink-block`（顶栏 + 主按钮 + 事件条）合计 ≤ 屏高 30%，否则变成"深色 App"，纸感尽失。
10. **安全区漏处理**：顶栏 `padding-top: calc(10px + var(--sat))`；底部按钮 `padding-bottom: calc(16px + var(--sab))`；PC 模拟器下 `env()` 为 0，需验证不塌陷。
11. **长中文断行**：标题加 `line-break: strict; word-break: break-word; overflow-wrap: anywhere`，禁标点行首。
12. **硬阴影在遮罩上失效**：弹窗阴影用 `rgba(26,24,21,.22)` 而非纯 `--ink`，否则深 scrim 上看不出层次。
13. **禁用动画属性**：不要动画 `box-shadow`、`filter: blur()`、`background-position` —— 移动端必掉帧且硬阴影留残影。
14. **数字跳动**：数值容器加 `font-variant-numeric: tabular-nums; font-family: var(--font-mono)`，否则资源面板刷新时左右抖。
15. **号外条滥用**：随机事件一局 ≤ 3 次，多了冲击感钝化且遮挡正文。
16. **不要 emoji**：基调是严肃 + 黑色幽默，emoji 瞬间破功；图标一律内联 SVG 或 CSS 几何图形。
