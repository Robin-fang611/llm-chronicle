# R1 · 讨论 Discussion / Retro

## 本轮改善了什么

从零到「内容 + 逻辑 + 工具链」三层就位。最关键的一点：**内容层与逻辑层彻底解耦**——
`content.js` / `archives.js` 是纯数据，`state.js` / `logic.js` 是纯规则，
两者都不碰 DOM，因此可以在 node 里直接加载做回归测试，无需浏览器。
这解决了这个项目最大的风险（小红书小工具无法在开发环境用真机调试）。

其次是**流程预生成 + 随机数状态入 state**：把「随机事件」这类不确定因素变成确定性的
`flow` 数组，让「同 seed 完全可复现」和「进度条显示准确总数」两个需求同时成立。

## 剩余风险

| 风险 | 影响 | 下轮动作 |

| 完全没有 UI，无法目视验证 | 高 —— 视觉规范尚未落地一寸 | R2 立刻做核心循环 |
| 平衡基于随机模拟，非真人手感 | 中 | R5 用「目标导向模拟」复核各路径是否「想成为谁就大致能成为谁」 |
| 12 个决策 + 最多 3 个事件 = 最多 15 步，是否疲劳 | 中 | 策划案 §13 已列此风险；先按 12 做，实测再砍 |
| 反事实档案的写法较新，需真人读感验证 | 低 | R4 完成后通读一遍文案 |
