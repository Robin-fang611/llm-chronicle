# R6 · 把"只能靠眼睛看"的部分收进测试

> 前五轮里唯一没被自动验证的是视觉。本轮把它变成可断言的规则。

## 为什么要做

R5 结束时 DoD 8 条已全过，但"四视口 / 对比度 / 直角 / 硬阴影"这些
美术规范里的要求，只靠人工核对 CSS，没有一条被自动断言过。
一旦后面再改样式，就会悄悄退化。

于是新增 `tools/test-visual.js`：用 WCAG 2.1 相对亮度公式**实算**对比度，
再静态扫描 CSS 校验直角 / 硬阴影 / 字号下限 / 禁用装饰 / 安全区 / 断点。

## 第一个收获：美术规范文档自己标注的对比度是错的

```
--ink     ：文档 12.9:1 / 实算 13.85:1
--accent  ：文档  5.1:1 / 实算  4.64:1   ← 文档高估
--info    ：文档  5.4:1 / 实算  6.09:1
--success ：文档  4.6:1 / 实算  4.83:1
--warn    ：文档  3.2:1 / 实算  2.61:1   ← 文档高估，且低于 WCAG 最低 3:1
--gold    ：文档  3.6:1 / 实算  2.84:1   ← 文档高估，且低于 WCAG 最低 3:1
```

这份文档的危险之处在于：它基于"warn 3.2:1、gold 3.6:1 都 ≥3"这个**错误前提**，
得出"这两个色可以用于图标+加粗短标"的结论。实算都不到 3:1——
照着文档用，就会做出不达标的界面。

## 修了 4 处实际用色

| 位置 | 问题 | 修法 |
|---|---|---|
| `.archive-card-badge`（"已解密"文字） | 用 `--gold`，实算 **2.84:1** | 改用 `--success-deep`（6.2:1） |
| `.opt-tag.is-good / .is-bad`（卡片后果标签） | `--success` / `--accent` 在卡片纸 paper-2 上只有 4.19 / 4.02:1，小字号需 4.5:1 | 新增 `--success-deep #2E5033` + 已有的 `--accent-dark`，实算 6.2 / 5.8:1 |
| `.start-tag`（开始卡标签） | 卡片纸上用原色 `--accent`，4.02:1 | 改 `--accent-dark` |
| `.star` / `.star-dot`（星级填充） | 金色填充 + 金色边框，图形轮廓辨识度仅 2.84:1 | 改成**金填充 + 墨黑边框**，由边框提供可辨识性 |

## 加了两道"防退化闸门"

以后谁再在低对比度位置用错色，测试会直接拦住：

- `--warn` 一旦被当文字色使用 → 立即失败（当前未使用，一旦引用就会触发）
- `--gold` 只能作填充，且**每一处都必须配深色边框**
- 原色 `--accent` 作文字时，选择器必须在"亮底白名单"内
- 原色 `--success` 一律不得作文字色

## 覆盖到的规则（30 项）

**对比度（实算）**：正文墨黑/主背景 13.85:1、次级文字、三级文字、
套红、信息蓝、成功绿、警示/成就金、反白字、加深版红绿、白字套红底……

**CSS 规则**：无圆角 >2px · 阴影零模糊且无 blur · 动效只用 transform/opacity/clip-path
· 正文 ≥16px · 最小字号 ≥12px · 无位图/外链/woff/emoji · 反白块 ≤4 处
· `prefers-reduced-motion` 全局降级 · 安全区四边 · 四视口断点齐全
· 噪点 opacity ≤0.05 · 网点间距 ≥4px
