# R5 · 精修：修掉一个"游戏不成立"级别的判定 bug

> 本轮是五轮里价值最高的一轮——它把一个"玩起来很挫败"的游戏改成了"玩起来有因果感"的游戏。

## 审核发现：目标导向测试全军覆没

R4 只验证了"随机瞎选能覆盖 10 个结局"，但这不够。
真正该验证的是策划案 §13 自己列出的风险：**「路径判定不透明——玩家不知道自己为什么走到这个结局」**。

于是新增了一条测试：模拟"我就是想成为 X"的玩家（每次选对该路径贡献最大的选项），
看他能不能成为想成为的人。

```
目标导向命中率 → 奥特曼 100%  达里奥 100%  杨植麟 45%  梁文锋 100%  杨立昆 0%  哈萨比斯 0%
```

**杨立昆 0%、哈萨比斯 0%** —— 想成为也成不了。游戏在这两条路上是"死"的。

## 根因一：判定顺序错误（致命）

`judgeEnding` 原本按结局的 `order` 字段从小到大遍历，取第一个满足门槛的。
而 `altman` 的 order=3 排在最前面，它的门槛（资金 ≥50 亿、算力 ≥5 万卡、拿过大额融资）
又最容易在"顺手拿笔大钱"时被动满足。

结果：**任何路线走到第三幕只要选了「拿超大轮」，就会被判成奥特曼**，
无论你前两幕多么坚定地走开源 / 走研究 / 走安全。

这违背了策划案 §3.5 的原文：
> 结局 = argmax( pathScore[6条] ) 且 满足该路径的准入门槛

**修法**：重写为三段式
1. 失败结局（破产 / 被驱逐 / 护城河蒸发）—— 由资源状态直接触发，优先级最高
2. **成功结局按六条路径的倾向分降序**匹配，取第一个满足门槛的
3. 都不满足 → 兜底「安静地活着」

修复后：`杨立昆 0% → 100%`、`哈萨比斯 0% → 100%`

## 根因二：第三幕没有月之暗面和 Meta 的分数

杨植麟仍卡在 45%。调试输出显示，未命中时：

```
openai 19 分  >  moonshot 17 分
```

因为 **D10（要不要继续融资）/ D11（安全 vs 速度）/ D12（最后一注）这三个决胜节点
完全没有 moonshot 和 meta 的路径分**。走这两条路的玩家，在最关键的三步拿不到任何分，
只能眼睁睁被 OpenAI 反超。

**修法**：按人物真实特征补齐第三幕路径分
- `D10_b` 拿战略投资 → +moonshot 2（月之暗面拿过阿里、腾讯的战略投资）
- `D10_d` 上市 → +meta 1, +deepmind 1
- `D11_a` 速度优先 → +moonshot 2（Kimi 快速迭代 + 激进投流）
- `D11_c` 走中间路线 → +meta 1
- `D12_c` 押极致成本 → +moonshot 2
- `D12_d` 押多模态 → +moonshot 1（K2.5 原生多模态）

顺带下调两个随机事件的现金惩罚（`e_chip_a` -25→-18、`e_trillion_a` -45→-35），
避免"激进投流 + 囤卡 + 军备"三连直接击穿现金流。

## 修复后

```
目标导向命中率 → 奥特曼 100%  达里奥 100%  杨植麟 100%  梁文锋 100%  杨立昆 100%  哈萨比斯 100%
```

随机瞎选分布（3000 局，10 个结局全部可达）：

```
quiet_life 37.2%   altman 18.2%   acquired 16.4%   yang 9.3%
amodei 6.4%        liang 5.8%     ousted 3.4%      hassabis 1.8%
lecun 1.2%         moat_gone 0.3%
```

判读：瞎玩大概率"安静地活着"（兜底 37%），
但**只要带着目标玩，六条路 100% 都能走到**——这正是创业模拟器该有的手感：
成功要选对，而不是靠运气。
