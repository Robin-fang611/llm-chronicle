# R2 · 讨论 Discussion / Retro

## 本轮改善了什么

游戏从「看不见的逻辑」变成了「点得动的完整循环」：开始 → 12 个决策（穿插号外事件）
→ 结局卡 → 真实档案 → 成绩卡 → 档案柜，全链路可点、可通关、可存档续玩。

最有价值的不是 UI 本身，而是**新增的 UI 冒烟测试**。它用不到 200 行的自写 DOM shim，
在没有浏览器的环境里抓出了 3 个真 bug ——其中「档案永远解锁不了」和
「下一题问题配上一题回声」这两个，靠肉眼点测很可能要玩好几局才发现，
而在小红书小工具的环境里根本没有调试手段。
