## 0. 背景（v5 遗留问题清单——用户体感「重复 + bug」的根因）

1. **生活题选项库「按档位固定、三年共用」**：18 岁档在「选专业/大二/毕业求职」三个不同场景看到同一组选项（计算机/喜欢的事/混着）；22 岁档「工作第二年」出现「进大厂哪怕996」（语境错位）；25 岁档「转型第一年」出现「跳槽去风口」（语境错位）——玩家强烈感知「每次都是这几个选项」。
2. **中段卡文案 bug**：「继续走完剩下五年」（中段 2024 → 结局 2026 仅剩 2 年）；「前半生你的三个关键选择」（18 岁档 2024 才 25 岁）。
3. **中段卡气质进度失效**：`state.personality` 只在结局计算，中段永远 4 个「?」却写死「2/4」（审计发现）。
4. **AI 姿态 A 半区整体不可达**：aiDep 排期内上限 29/31/33，人格判据「≥50=A」永远为假 → 16 型死掉 8 个（AGTI/AGTO/AGPI/AGPO/ASTI/ASTO/ASPI/ASPO），成绩卡示例「ATGI」是死代码（审计发现）。
5. **25 岁档 D6 与 S3@2021 三组选项逐字重复**（审计发现——D6 三选项回声/生活线与 25 岁档 q3 相同）。
6. **可复现性缺口**：`{模型代际}` 无定义；号外 b1/b2 缺倾向分；b3-b6 保留数据无文档全文；{裸辞那年} 多次裸辞取次未定义；§9.1 「否则按人脉>技能 判P」语义含混；jump 计数无字段定义（审计发现）。

## 7. 补充轮 · 决策防误触改选（Robin 新需求，2026-08-30）

**需求**：选中选项后点「继续」前不锁定、可改选，防误触。

**方案**：结算时点从「点选瞬间」移到「点继续瞬间」——`state.choose()` 仅记录 `_pending`（不调 Logic.choose）；`state.advance()` 出口先结算 `_pending` 再推进。改选 = 替换 `_pending`，只记一次（最后一次选择）。

**落地**：
- `state.js`：choose 只记录 / advance 出口结算（改选不重复记账；flag/倾向同样以最后一次为准）
- `ui.js`：选中后其它选项**不禁用**（去掉 disabled 分支），高亮随改选转移；新增提示「想改主意？再点一次别的选项。」（.hint）
- 策划案-v6：新增 §1.3 防误触规则（5 条硬性）+ §1 玩法总述 3 更新 + §11.5 决策页构成更新
- `tools/test-ui.js`：新增 2 项回归（未锁改选不结算 / 最后一次为准只记一次）
- `tools/test-doc.js`：新增 §1.3 文档↔代码闭环断言（choose 不结算、advance 才结算）

**验证**：test-logic 37 / test-ui 31 / test-visual 27 / test-doc 13 / lint 0；balance 10/10 可达不变；E2E（390×844）选1→改选2→继续 全链路 ✓（高亮转移/资源未变/回声切换/继续后结算/零 JS 错误）。
