## 0. 角色与总目标

你是《大模型编年史 · 我们这十年》的**视觉设计负责人**。这是一款挂在小红书笔记里的纯离线 H5 人生决策模拟游戏（移动端竖屏 375-430px），玩家从 2017-2024 任选一年、以 18-25 岁任一年龄穿越回去，一路做生活决策走到 2026 年。目标玩家是 22-32 岁、曾被"AI 要替代我"吓到过的小红书用户。

你的任务：**推翻 v1 的全局气质，重新设计一套"生活气"导向的前端视觉风格体系**，产出《美术设计规范-v2.md》。体系必须同时满足：

1. 含**多套完整可切换的视觉模式**（换一个主色不叫一套模式）；
2. 提供**64 种开局组合（年份 2017-2024 × 年龄 18-25）与视觉的一一对应方案**——玩家落进任何一格，看到的样子的答案是确定的；
3. 整体气质**偏生活气**：像翻自己的相册、记账本和聊天记录，不像读一份判决书；
4. 服务最高设计理念：**减少普通人对 AI 的焦虑**。

## 2. 北极星：减少 AI 焦虑（全部设计由此推导）

### 2.1 一句话理念

> **AI 不是考官、不是对手、不是末日预言；它是十年里悄悄住进你手机的一个工具。整个游戏看起来要像"翻自己十年的生活"，而不是"读一份关于 AI 的判决书"。**

### 2.2 五条转化原则（每条都要落成具体视觉规则写进文档）

1. **AI = 生活背景音**：AI 在画面中永远以"生活物件"的形态出现——输入法联想条、语音助手小圆点、相册回忆推送、外卖软件的优惠券。禁止把 AI 画成主角。
2. **警示降噪**：裁员、降薪、诈骗、换脸网暴等史实**不许粉饰也不许删**（策划红线），但视觉必须"降档"处理：负面事件用"旧新闻剪报、便签、账本红字批注"的语气呈现。禁止警报红大底、禁止闪烁、禁止倒计时。
3. **失败留一线**：三个警示结局（被浪吞 / 反诈 / 茧房）与瓶颈状态（资金见底 / 心态崩溃）的卡面必须仍留暖色与"第二天"的意象（呼应策划案 §14"落点永远是太迟的第二天"）。禁止"淘汰 / 出局 / Game Over"式隐喻（红叉、碎裂、熄灭的灯）。
4. **暖色底盘，心态优先**：全模式主底色必须是暖色系（人间烟火色域），冷色只做小面积点缀。"心态"资源的视觉权重应不低于"存款"——这是一个讲松弛感的游戏。心态走低时的视觉表达规范为"疲惫的暖光"，不是崩溃红。
5. **人比机器大**：一切贴纸位、插画位、印章位的视觉主角是"人的生活"（饭桌、通勤、出租屋、课堂）；机器只出现在配角位置，且尺寸不大于生活物件。

### 2.3 意象黑白名单（写死进文档）

- **黑名单（禁止出现）**：机械臂/机器人、发光大脑、电路纹路、蓝色科技 HUD、骷髅/末世/废土、红色警报灯、倒计时、渐变玻璃拟态、荧光绿终端字、"AI 即将取代人类"式大字标语。
- **白名单（鼓励使用）**：台灯、饭碗、地铁卡、泡面、绿植、电动车、快递单、课程表、相册、聊天气泡、记账本、钥匙串、晾衣绳、夜灯……你需要扩充至 ≥24 项并成库（见 §4.2）。

## 3. 多套模式体系（本任务核心交付）

### 3.1 架构：模式库 ⊕ 年代滤镜 ⊕ 人生阶段层

最终视觉 = **基础模式（定基调）** 叠加 **年代滤镜（由年份决定）** 叠加 **人生阶段层（由年龄档决定）**：

| 层 | 由什么决定 | 档位 | 掌管什么 |
|---|---|---|---|
| 基础模式 | 设计者定义（见 §3.2 命题） | **4-6 套** | 色板全套 token、载体隐喻、组件性格、动效性格 |
| 年代滤镜 | 游戏内年份 | 4 档：2017-2019 / 2020-2022 / 2023-2024 / 2025-2026 | 时代物件、纹理强度、饱和度与明度微调、印章风格 |
| 人生阶段层 | 年龄档 | 3 档：18-20 校园 / 21-22 毕业 / 23-25 职场 | 贴纸符号、卡片角标、生活线气泡样式 |

- **命题方向（可推翻，推翻必须给理由）**：基础模式建议从"人生情绪"出发而非"年代"出发（年代已由滤镜层掌管）。候选载体隐喻：记账本、老照片、课程表、聊天记录、台灯下的书桌、火车票根……每套模式绑定一个核心生活载体，全部界面元素从该隐喻推导。
- **年代滤镜覆盖全局长**：开局只到 2024，但游戏内时间会推进到 2026。第 4 档（2025-2026，"现在"）应是最亲切的当下感——结局发生在玩家真实生活的年份。文档必须定义**游戏内年份推进时滤镜的过渡方案**（时间在身边流过的体感），以及开局 64 格所用档位（前 3 档）与局内档位的衔接。

### 3.2 每套基础模式的必含内容（逐套给全，缺一不可）

1. 命名 + 一句话气质 + 适配的人生情绪（对齐 §3.1 独白的哪一类）；
2. **完整 CSS token 表**：纸系/墨系/套色/遮罩/纹理，格式对齐 v1 §6，直接可抄；每个色值给 HEX 并标注对比度；
3. 核心载体隐喻，及其在七屏上的体现方式；
4. 组件性格差异：决策卡 / 选项卡 / 资源面板 / 按钮在本模式下的具体变体（几何、阴影、圆角策略）；
5. 动效性格（快/慢、利落/绵软）与 1 个标志性动效；
6. 40 字模式示例文案一段（开局预览口吻），证明这套模式"说话的声音"；
7. 区分度自证：3 组"同一元素在不同模式下的对照描述"（文字描述即可），证明不换主色也能肉眼区分。

### 3.3 64 格映射总表（硬性，一格不缺）

- 输出一张 **8 行（年份）× 8 列（年龄）= 64 格**的完整总表，每格注明：`基础模式 + 年代档 + 阶段档 + 档案号印章样式`。
- 映射必须**确定性**（纯函数，无随机），且必须有**设计依据**：逐格对照策划案 §3.1 的 64 条独白与 §4.1 的 64 条题面提炼情绪，让最重的一格（如 2022×23"最好的朋友被裁了"）与最轻的一格（如 2017×18"刚办完入学"）拿到肉眼可辨的不同处理。禁止机械按行列平涂；成片共享同一模式的格子，须说明"为什么这一片共享同一种情绪"。
- 档案号印章 `NO.{Y}-{A}` 给出按年代档变化的印章规格（形状 / 字体 / 做旧程度）。

### 3.4 切换机制（开局滑杆 = 64 连续换肤）

开局页双滑杆每动一格，页面主题即时响应。文档必须给出切换实现方案（CSS 变量过渡 / 双层交叉淡入等）、过渡时长、性能约束（只动 opacity/transform/颜色变量，禁 layout 抖动）、reduced-motion 降级。目标是"每拨一格 = 翻开另一种人生"的体感，且切换过程不得闪烁、不得可读性下降。

### 3.5 全模式不变量（红线）

以下内容**跨 64 格全部一致**，任何模式不得破坏：布局几何与信息架构、字号阶梯与行高、48px 最小触控高度、正文对比度 ≥ 4.5:1（大字 ≥ 3:1）、状态色的冗余编码、安全区处理、零外链零位图。生活气不许以牺牲可读性为代价——暖色系最容易翻车在对比度，每个色值必须实测标注。

## 4. 「生活气」落地手法

### 4.1 载体隐喻制

v1 是单隐喻（一切皆报纸档案）；v2 要求"**每屏一个生活载体**"：开局页是什么（摊开的笔记本？车票？）、决策页是什么（压在课桌上的一张便签？）、生活线是什么（聊天记录气泡？）、结算卡是什么（账本对账页？）、结局卡是什么（十年后翻到的一页相册？）……七屏逐一指定载体并写明理由。载体之间要像"同一个人书桌上的东西"——成体系、不散装。

### 4.2 生活物件符号库

建立 ≥24 项的"生活物件"几何符号库（纯 CSS/SVG 绘制规范，含绘制网格与最小尺寸），替代 v1 的"工牌/毕业照"角标体系。符号按人生阶段层分组，供 64 格映射调用。绘制风格必须统一（线条粗细 / 圆角策略 / 做旧处理，三选一并写死）。

### 4.3 排印

- 在"系统字体栈、零外链"硬约束内解决"手写感/生活感"：给出**三字体分工方案**——楷体（KaitiSC/KaiTi）用于批注与生活线、宋体用于史料引文、黑体用于 UI 主体，并写明 Android 缺字体时的降级链与真机验证方法。
- 中文标点悬挂、数字的账本感（tabular-nums）、小红书口吻的排印处理（如"那年 22 岁"里数字的强调方式）。

### 4.4 emoji 红线（维持）

装饰与图标**继续禁用 emoji**（跨端渲染不一致不可控，与现有 lint 一致）。生活气由载体隐喻与符号库承担，不靠 emoji。文案层是否使用 emoji 不在本规范管辖，但视觉设计不得依赖 emoji 存在。

## 5. 七屏逐屏规范要求（对齐策划案 §12，一屏一节）

每屏必须给出：信息架构（元素清单与层级，对齐策划案对应章节）、多模式下的不变量与可变量、该屏的生活载体、状态全覆盖（默认/选中/按下/禁用/临界/解锁）、入场动效。

1. **开局页**：双滑杆是全游戏第一交互主角——滑杆本身的生活化造型（不许是冷感系统滑杆）、64 格预览文案即时刷新、档案号印章、开始按钮。滑杆的每一次拨动都要"值回票价"。
2. **决策页**：顶部资源面板（存款 / 技能 / 人脉 / 心态 4 列，注意 v3 已改资源名；心态有独立视觉地位，含走低的"疲惫暖光"规范）、进度页眉（年份 + 第 X/Y 个决定 + 模型代际）、场景卡、2-3 个选项卡（后果标签按 §2.2 反焦虑语气处理）、选定后的"回声"横条（史料感）+ "生活线"横条（生活气主载体）的双条节奏。
3. **号外条**：保留"砸下来"的戏剧性但按 §2.2 降噪；给出 6 种号外（ChatGPT 爆火 / 反诈 / AI 面试官 / 换脸网暴 / DeepSeek / 工位顶替）的变体规范，一局 ≤ 2 次。
4. **中段结算卡**：资源四宫格 + 三个关键选择时间轴 + 此刻气质（2/4，未判定维度显示"？"）+ 双按钮；"分享半场小结"复用本屏版式。
5. **结局卡**：档案卷宗·人生小传版式 + 人格印章（16 型，含稀有隐藏型 RGPI/RGPO）+ 年龄行"2026 年，你 {AGE} 岁"（20-34 全覆盖版式不塌）；鲜活结局与警示结局（留一线）两套处理。
6. **档案柜/档案页**：21 份双线档案（11 世界线 + 10 人生实录）、涂黑 CLASSIFIED 条、双线时间轴（墨色世界线 / 生活线）；这是 v1 报纸档案风最合理的保留地，处置方案在此写清楚。
7. **成绩卡**：Canvas 长图分享（开局参数行"2017 年 18 岁 → 27 岁" + 活法 + 气质代码 + 档案进度）。**多模式下必须仍可生成，且在小红书信息流里"跳出来"**——生活气偏灰暖，信息流里易沉底，必须给传播性专门方案（标题字 / 印章 / 主色的封面级对比），并给 3 套不同模式下的成绩卡版式示例描述。

## 6. 硬约束（工程红线，沿袭项目既定约束）

- 纯离线 H5：零外链、零 `@font-face`/woff、零位图；图形一律纯 CSS + 内联 SVG（feTurbulence 噪点 data-uri 可用）。

- 移动竖屏 375-430px 优先，安全区 `env(safe-area-inset-*)`；动效只动 transform/opacity/clip-path；`prefers-reduced-motion` 全量降级。
