# Spec · 《大模型编年史》v4 修正（选择修复 + 时间线一致性 + 策划案可复现化）

> 日期：2026-08-30 · 执行者：ZCode 主会话
> 依据：《AGENTS.md》长任务 Spec 驱动；目标物 = `build/`（小红书 H5 静态包）+ `策划案-v4.md`

## 0. 背景（Robin 反馈的两个问题）

1. **年龄/年份不能选**：线上版本（https://6017251f96d7406cb7fca9144d96a9a1.app.workbuddy.link）开局页滑杆拖不动，
   游戏永远是「2017 年 18 岁」。
   - 根因（已复现）：`ui.js renderOpening()` 在 `UI.show()` 把节点挂进 DOM **之前**调用 `bindSlider()`，
     `bindSlider` 用 `document.getElementById('sl-year')` 查找 → 元素尚在文档树外 → 返回 null → 静默不绑定。
     滑杆显示正常但无任何事件监听。`test-ui.js` 直接调 `HANDLERS.onSlide()` 绕过该路径，所以没抓到。
2. **时间线错乱**：2018 开局次年（2019）就出现疫情节点；D4「AI 提效」放在 2021 却配 2024 回声；
   号外 b1 在 2023/2024 开局也触发（策划案 §6.3 明令「2023 起开局不再出现」）等。
   - 根因：策划案只写了「决策数分档」，**没规定每一步的年份与年龄**；实现里硬编码（`D4b 在 Y+1`、`D3/D4 年龄 A+3/A+4`）。

## 1. 目标

1. 滑杆真正可选（年份 2017–2024 × 年龄 18–25，64 组合全生效，预览/印章/模式实时联动）。
2. **时间线全线一致**：任一开局年份下，每个步骤的年份、年龄、内容年代三者自洽；
   疫情节点只出现在 2020 年；号外按确定规则排期。
3. `策划案-v4.md` 成为唯一权威：任何人照它实现，得到与本包除美术外完全一致的游戏。
4. 全套测试（逻辑/UI/视觉/lint）+ 新增「时间线一致性」「真实滑杆交互」「文档↔代码一致性」测试全绿。
5. 子代理对照 v4 独立审阅通过。
6. 重新部署到原链接（同一 deployTarget 覆盖），交付手机端地址；重建 `大模型编年史.zip`。

## 2. 明确不做（范围外）

- 不改美术风格/布局/CSS 视觉（`style.css` 仅当新增 DOM 需复用样式，用既有 class）。
- 不改 21 份档案正文、10 结局的准入数值**除非平衡模拟证明某结局不可达**（改动会回填本文档与策划案）。
- 不重写 64 条开局独白/128 条题面的文字（仅修 3 处内嵌年龄 off-by-one，见 §4.3）。
- 不新增玩法系统（无新资源/新结局/新节点题）。

## 3. 时间线模型（v4 权威规则，写入策划案 §6.0）

年龄公式：`step.age = A + (step.year - Y)`。每步年份由下表唯一确定。

**核心步骤**（号外插入前）：

| 开局年份 Y | 步骤序列（节点, 年份） |
|---|---|
| 2017/2018/2019 | q1(Y) → q2(Y) → D3(max(Y,2019)) → D4b(2020) → D4(2024) → mid(2024) → D5(2024) → D6(2025) → D7(2025) → D8(2026) → D9(2026) → end(2026) |
| 2020/2021 | q1(Y) → q2(Y) → D3(Y) → D4(2024) → mid(2024) → D5(2024) → D6(2025) → D7(2025) → D8(2026) → D9(2026) → end(2026) |
| 2022 | q1(2022) → q2(2022) → D3(2022) → D4(2024) → mid(2024) → D5(2024) → D6(2025) → D7(2025) → D8(2026) → D9(2026) → end(2026) |
| 2023/2024 | q1(Y) → q2(Y) → D3(Y) → D4(2024) → mid(2024) → D5(2024) → D6(2025) → D7(2025) → D8(2026) → D9(2026) → end(2026) |

**号外排期**（每局恰好 2 次；插入规则：排在「年份 ≤ 事件年 的最后一个步骤」之后）：

| 开局年份 | 号外 1 | 号外 2 |
|---|---|---|
| 2017–2021 | b1(2022.11) | b2(2023) |
| 2022 | b2(2023) | b4(2025) |
| 2023 | b2(2023) | b3(2024) |
| 2024 | b2(2024) | b6(2024) |

- b1 仅 Y ≤ 2021（2022 开局的 q2 题面已内嵌 ChatGPT 发布）；b6 仅 Y = 2024（短局专用）。
- b5 不进任何排期（其内容与 D7 重复，D7 全开局必现）；数据保留。
- 决策总数：2017–2019 = 12；2020–2024 = 11。

**节点内容年代绑定**（回声/场景中的年份必须等于步骤年份，测试断言）：
D3「算法/短视频」2019 起 · D4b「疫情」= 2020 · D4「AI 提效」= 2024 · D5「裁员」= 2024 ·
D6「重算账」= 2025 · D7「DeepSeek」= 2025 · D8「风口」= 2026 · D9「回首」= 2026。

## 4. 落地改动清单

### 4.1 ui.js（滑杆修复 + D9 回看 + 生活线过滤）
- `sliderRow` 返回输入框引用，`renderOpening` 直接对元素绑定 `input` 监听（不再依赖 `getElementById` 时序）。
- `renderOpening` 支持 `extra.canResume` → 显示「继续上次」副按钮。
- `renderDecision` 中 D9 步骤追加「这些年你做过的关键选择」列表（复用 `.key-choices/.kc-row` 样式，取 significance 前 5，带年份）。
- `renderArchivePage` 与 `exportArchive`：生活线按「开局年份 ≤ 条目年份 ≤ reachedYear」过滤（'?' 反事实仍按 reached≥2024）。

### 4.2 logic.js
- `buildPlan` 按 §3 表重写（无硬编码年龄）；`flagYears` 记录每个 flag 首次出现的年份。
- 新增 `Logic.endingParams(state)`：返回结局模板占位符数据 `{AGE, 裸辞那年, 被优化那年, 开局那年, 裁员那年, 2023那年前后}`。

### 4.3 content.js
- q1 三处内嵌年龄 off-by-one：`2019-25`、`2020-25`、`2022-25` 的「你 26 岁」→「你 25 岁」。
- D8 场景 `你 30 岁上下` → `你 {AGE} 岁`；D9 场景 `那年 18 岁（或 25 岁）的你` → `那年 {START_AGE} 岁的你`。
- D9 标题去掉「十年前」；结局文案「这十年/十年过去了」→「这些年/这些年过去了」；D 结局「2021 年你有了首付」→「后来你有了首付」；I 结局「被喂到了 30 岁」→「被喂到了今天」。
- `era`/`breaking` 数据结构不变（b5 保留数据、不进排期）。

### 4.4 main.js / state.js
- `boot()`：一律先到开局页；有未完成存档时 `extra.canResume=true`；`onResume` 恢复存档。
- `onRestart`：保留本局年份×年龄（`newGame(startYear, startAge)`）。
- state.js 不变（serialize 已剔除瞬时态；flagYears 非瞬时，随存档走）。

### 4.5 测试
- `tools/test-logic.js`：新增「时间线一致性」块（§3 全部规则断言：每步 age 公式、年份单调、D4b 仅 Y≤2019 且 @2020、b1 仅 Y≤2021、b6 仅 2024、每局恰 2 号外、b2 全开局、D4/mid/end 年份、决策数 12/11、内容回声年份 ↔ 步骤年份）。
- `tools/test-ui.js`：新增「真实滑杆事件」测试（对渲染出的 input 派发 input 事件，断言数值标签/预览/stamp/state 联动）；补「继续上次」「再来一局保留参数」。
- 新增 `tools/test-doc.js`：解析 `策划案-v4.md` 的表格，断言与 content.js / buildPlan 一致（文档 ↔ 代码闭环）。
- 新增平衡模拟脚本（随机 3000 局分布 + 目标导向 10 结局可达性），结果写进本文档进度区；若某结局不可达 → 调准入数值并回填策划案。
